# 💰 FinancePulse — Production-Ready AdSense Monetized Web App

**FinancePulse** is a responsive, privacy-focused financial management web application built to deliver high user engagement and generate **Google AdSense passive ad revenue**.

![FinancePulse](assets/favicon.svg)

---

## 🌟 Features & Pages

- 📊 **Dashboard (`index.html`)**: Real-time spending charts, savings overview, recent transactions.
- 🎯 **Budget Planner (`budget.html`)**: Category targets vs actual spending visual progress bars.
- 💳 **Expense Tracker (`expenses.html`)**: Income/expense log, category filtering, CSV export.
- 📈 **Investment Calculator (`investment.html`)**: Compound interest simulator with interactive growth line graph.
- 🐖 **Savings Goal Tracker (`savings.html`)**: Interactive progress bars and deposit tracker.
- ⚡ **Debt Payoff Planner (`debt.html`)**: Avalanche & Snowball strategy algorithms.
- 🏛️ **Net Worth Tracker (`networth.html`)**: Assets vs Liabilities ratio calculator.
- 💱 **Currency Converter (`currency.html`)**: Live FX exchange rates converter.

## 💵 How to Monetize with Google AdSense

1. **Deploy to GitHub Pages, Netlify, or Vercel**:
   - Host this repo for free on Netlify or Vercel with 1 click.
2. **Apply for Google AdSense**:
   - Submit your live domain URL at [google.com/adsense](https://www.google.com/adsense).
3. **Insert AdSense Code**:
   - Replace the `.ad-slot` HTML blocks across the `.html` files with your AdSense `<script>` units.
